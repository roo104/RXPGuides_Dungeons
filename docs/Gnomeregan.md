### Gnomeregan

15. 🔁 *Along the way*
    - Kill **Gnomeregan mobs**. Loot them for their **Robo-mechanical Guts**
    - 🎯 Robo-mechanical Guts (24) — [Gyrodrillmatic Excavationators](https://www.wowhead.com/forever/quest=2928)
16. 🔁 *Along the way*
    - Open the **Artificial Extrapolators**. Loot them for **Essential Artificials**
    - 🎯 Essential Artificial (12) — [Essential Artificials](https://www.wowhead.com/forever/quest=2924)
17. 🔁 *Along the way*
    - ⚠️ If you loot an **Engraved Ring**, use it to start Return of the Ring
    - ❗ Accept [Return of the Ring](https://www.wowhead.com/forever/quest=79987)
18. *Optional*
    - 💬 Talk to **Kernobee** in The Dormitory, right outside the gnomish safe zone
    - ⚠️ This starts an escort quest. The turn-in is with Scooty in Booty Bay, so only take it if you are going there
    - ❗ Accept [A Fine Mess](https://www.wowhead.com/forever/quest=2904)
19. *Optional*
    - Escort **Kernobee** to the Clockwerk Run exit
    - 🎯 Kernobee Rescue — [A Fine Mess](https://www.wowhead.com/forever/quest=2904)
    - *Only if you have [A Fine Mess](https://www.wowhead.com/forever/quest=2904)*
20. Kill **Mekgineer Thermaplugg**
    - 🎯 Mekgineer Thermaplugg slain — [The Grand Betrayal](https://www.wowhead.com/forever/quest=2929)
21. *Optional*
    - ⚠️ If you looted **Thermaplugg's Engineering Notes**, use them to start The Mad King
    - ❗ Accept [The Mad King](https://www.wowhead.com/forever/quest=80324)
22. Finish looting **Robo-mechanical Guts** and **Essential Artificials** before you leave
    - ⚠️ The Artificial Extrapolators respawn after a few minutes
    - 🎯 Robo-mechanical Guts (24) — [Gyrodrillmatic Excavationators](https://www.wowhead.com/forever/quest=2928)
    - 🎯 Essential Artificial (12) — [Essential Artificials](https://www.wowhead.com/forever/quest=2924)
